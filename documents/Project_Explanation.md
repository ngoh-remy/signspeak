### Abstract
Traditional communication models often marginalize non-verbal and deaf individuals because sign language is not universally understood. This research resolves this gap by designing a high-performance web platform that captures video via consumer webcams, extracts physical landmarks, and evaluates the temporal gesture structure using recurrent neural networks (LSTMs). The platform produces audio and text instantly, presenting a practical, cost-effective substitute for human interpreters.

---

## System Architecture

The application consists of three modular layers interacting synchronously for ultra-low latency.

### 1. Intelligent Frontend
*Technologies: React.js, Vite, Web Speech API*
- Captures high-resolution video streams from local cameras.
- Performs canvas rendering and packs frames for real-time networking.
- Establishes full-duplex communication over WebSockets.
- Synthesizes text responses into natural spoken voice.

### 2. Microservice Backend
*Technologies: FastAPI (Python), Uvicorn, SQLite*
- Handles user authentication using secure JWT tokens.
- Coordinates real-time frame pipelines via WebSocket routers.
- Logs validated translations into SQLite history databases.
- Exposes autogenerated REST documentation via OpenAPI.

### 3. Deep Learning Engine
*Technologies: TensorFlow, MediaPipe, NumPy*
- Extract coordinates from 500+ bodily landmarks in milliseconds.
- Feeds temporal landmark sequences into trained LSTM networks.
- Calculates probability distributions across the sign library.
- Returns prediction outputs and confidence scores.

## Defense Preparation Guide

Below are answers to critical questions you may face from the academic jury.

### Q1: Why choose MediaPipe instead of passing raw video frames directly into a CNN?
Passing raw video frames directly requires enormous convolutional neural networks (like ResNet or MobileNet) which are heavy, require active GPUs to run in real time, and easily overfit on video background settings (like lighting, clothing, and wall color). By using **MediaPipe Holistic**, we extract *only* coordinate locations of joints. The background is completely discarded! This makes the classifier incredibly lightweight, fully invariant to background noise, and capable of running at 30 FPS on a standard consumer laptop CPU.

### Q2: What is the purpose of the LSTM layers in your neural network?
Sign language gestures are not static images; they are temporal actions that occur over time. A CNN can classify a single frame, but cannot track the sequence of movement. An **LSTM (Long Short-Term Memory)** network is a type of Recurrent Neural Network (RNN) designed to process sequence datasets with feedback connections. It allows our network to remember historical movement frames and predict the sign once the full gesture completes, handling speed variations easily.

### Q3: How are WebSockets superior to HTTP requests for this system?
Standard HTTP requests are unidirectional and require creating a new TCP socket connection for every frame (polling). This introduces immense overhead, causing delays of 200ms - 500ms per frame. **WebSockets** create a single, continuous, full-duplex TCP connection. Once opened, frames are streamed continuously, and results return within 30ms - 50ms, enabling seamless real-time interaction.
